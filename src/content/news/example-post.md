This is an **example news post** included only to prove the Astro content
collection pipeline works end to end. It is not real content.

Real announcements — clinical milestones, regulatory updates, ALS-205 progress —
are supplied later by Cora. Each post is a Markdown file in

`summary`, `tag`, optional `draft`).

When `draft: true`, the post is hidden from the published News list.
